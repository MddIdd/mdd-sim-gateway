# 运行中的代理连通性提示

IMS 已注册只表示当前注册状态，不能保证此刻呼入、呼出和语音正常。已启用的代理线路
在正常时每十分钟通过当前出口进行一次 UDP 连通性检测；使用现有的多个 DNS/STUN 目标，
任一目标有有效响应即通过。两轮连续失败才显示「代理 UDP 连通性异常」，第一轮失败
显示正在复核，并在三十秒后再次检测；告警期间每分钟检测恢复，恢复后回到十分钟间隔。
手动指定的节点和只有一个节点的出口也会检测。

VoWiFi 卡片显示检测结果、最近检测时间和「重新检测」按钮。检测通过后自动清除警告；
切换节点、变更代理配置或出口状态过期时，旧结果不再用于判断。正常检测结果超过十二分钟、
异常或复核结果超过三分钟时显示待检测，正常等待下一轮时不会提前过期。
同一出口的线路共享一次检测，手动重复检测有十秒间隔。代理直连模式不进行代理检测。

这些结果只用于提示，不自动切换节点或重启线路，也不改变原有的 IMS 注册恢复策略。
公共 UDP 检测通过不代表运营商的 ePDG/IMS 路径或既有 UDP 会话必然正常；失败也不能
单独证明运营商故障。页面因此保留 IMS 注册事实，并将已确认的连续检测异常优先显示。
宿主模式需要使用同版本编排器发布配置标识；旧编排器的状态显示为待检测。
