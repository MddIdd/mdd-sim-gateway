# VoWiFi 来电故障采集（v1.14.2-rc2）

本测试版用于捕捉偶发的「能呼出、不能呼入」。尚未确认运营商相关故障的根因，
也不保证升级后故障消失。请在方便短暂中断线路时手动升级；自动更新目标仍为 v1.14.0。

1. 在「系统设置 → 备份与更新」的版本选择中切换到「测试版本」，选择 `v1.14.2-rc2` 安装。
   Control、Engine 和宿主编排器或 Hardware 容器应使用同一版本。
2. 等线路完成注册，在「诊断 → 支持包」找到「VoWiFi 持续采集」，选择故障线路，
   点击「开始 60 分钟采集」，等状态显示正在采集。
3. 从另一部手机直接拨入，尽量包含一次实际接听；分别标记「来电失败」「来电响铃」或
   「来电已接听」。首次失败后先保留现场一分钟，再测试呼出及回拨，分别记录结果。
   不必为了采集手动重新注册或重建线路，原有自动恢复仍正常工作。
4. 点击「停止采集」，下载本页的脱敏支持包，提交时附上测试时间、时区和听到的提示音。
   如一小时内未复现，可重新开始；重新开始会清除上一轮采集，请先下载需要保留的支持包。

采集自动到期，线路容器重建后会在剩余时间内继续。若提示采集器未响应，请确认 Engine
也已更新；若提示部分连接证据不可用，支持包仍会保留已取得的部分。

采集写入的内容包括 SIP 方法、状态码、Contact 有效期、协商端口及 SPI、TCP 状态和
报文头摘要、XFRM 计数，以及隧道地址变化。地址、SIP 用户与呼叫标识在写入时转换为
仅本次采集可关联的代号，不保存 SIP 鉴权头、消息正文、音频、IPsec 密钥或原始 pcap。
单类记录最多保留两个约 512 KiB 的文件，高流量时限速；支持包覆盖说明会标明导出截断。

RC2 还会在运行期间检测当前代理的 UDP 连通性，连续失败时优先显示警告，同时保留
IMS 已注册的事实。正常时每十分钟检测，可在 VoWiFi 卡片手动重新检测；检测通过
不能保证运营商通话链路正常。提示含义及频率见[代理连通性提示](PROXY_HEALTH.md)。
